3\section{Objekterkennung mit YOLO} \label{subsec:yolo_det}\section{Object Detection with YOLO} \label{subsec:yolo_det}
4Die automatische Bildanalyse lässt sich grundsätzlich in verschiedene Problemklassen unterteilen \cite{szeliski2022computer}. Während die reine Bildklassifikation lediglich die Frage beantwortet, ob ein bestimmtes Objekt in einem Bild vorhanden ist, geht die Objekterkennung einen Schritt weiter \cite{zou2023object}. Sie ermittelt nicht nur die Klasse des Objekts, sondern auch die genaue Position an der sich das Objekt befindet.Automatic image analysis can fundamentally be divided into different problem classes \cite{szeliski2022computer}. While pure image classification merely answers the question of whether a certain object is present in an image, object detection goes one step further \cite{zou2023object}. It determines not only the class of the object but also the exact position at which the object is located.
5In dieser Arbeit wird YOLO \cite{jocher2024yolo} in der Version 26 verwendet \cite{sapkota2025yolo26}. Im Gegensatz zu zweistufigen Detektoren, welche zuerst interessante Bildregionen extrahieren und erst im zweiten Schritt klassifizieren \cite{ren2015faster}, ist YOLO ein einstufiger Detektor, welcher das gesamte Bild in einem Durchlauf mithilfe eines Faltungsnetzwerk \cite{lecun1998gradient, krizhevsky2012imagenet} analysiert \cite{redmon2016yolo}. Das Bild wird in Raster unterteilt, jede Rasterzelle gibt das Netzwerk mehrere Begrenzungsrahmen und die zugehörigen Klassenwahrscheinlichkeiten und Konfidenzwerte voraus \cite{redmon2016yolo}. Der Begrenzungsrahmen ist der Rahmen in dem sich ein Objekt befindet. Die Klassenwahrscheinlichkeit gibt an wie wahrscheinlich das erkannte Objekt zur Klasse Katze gehört. Der Konfidenzwert hingegen gibt an, wie sicher sich das Netzwerk ist, dass es sich überhaupt um ein Objekt handelt \cite{ultralytics_confidence}.In this thesis, YOLO \cite{jocher2024yolo} in version 26 is used \cite{sapkota2025yolo26}. In contrast to two-stage detectors, which first extract interesting image regions and only classify them in the second step \cite{ren2015faster}, YOLO is a single-stage detector that analyses the entire image in one pass using a convolutional neural network \cite{lecun1998gradient, krizhevsky2012imagenet} \cite{redmon2016yolo}. The image is divided into a grid, and for each grid cell the network predicts several bounding boxes and the associated class probabilities and confidence scores \cite{redmon2016yolo}. The bounding box is the frame in which an object is located. The class probability indicates how likely it is that the detected object belongs to the class cat. The confidence score, on the other hand, indicates how certain the network is that there is an object at all \cite{ultralytics_confidence}.
6Für diese Arbeit ist YOLO unerlässlich, da ein solches System niedrige Inferrenzzeiten benötigt \cite{terven2023yolo}. Das Modell liefert für jede erkannte Katze die exakten Koordinaten dessen Gesichtes, was die Basis für die Objektverfolgung bildet.YOLO is indispensable for this thesis, since such a system requires low inference times \cite{terven2023yolo}. On the one hand, this is important so that the system remains reliable and the cat does not have to wait in front of the flap for too long. For each detected cat, the model delivers the exact coordinates of its face, which forms the basis for object tracking.
7\section{Mehrfach-Objektverfolgung mit ByteTrack} \label{subsec:bytetrack}\section{Multi-Object Tracking with ByteTrack} \label{subsec:bytetrack}
8Eine Objekterkennung wie YOLO alleine bewertet jedes Videoeinzelbild isoliert. Wenn sich eine Katze auf einem Video befindet, dann wird jedes Einzelbild des Videos separat betrachtet. Jede erkannte Katze ist also eine neue Katze. Durch eine Objektverfolgung wird es möglich, eine Katze über ein ganzes Video eindeutig zuzuordnen. Eine Mehrfach-Objektverfolgung ist dann die Erweiterung auf mehrere Katzen pro Video \cite{luo2021mot}. Das ist zwingend erforderlich um eine zeitliche Analyse einer bestimmten Katze durchführen zu können.An object detection model such as YOLO on its own evaluates each video frame in isolation. If a cat is in a video, each frame of the video is considered separately. Every detected cat is therefore a new cat. Object tracking makes it possible to uniquely assign a cat across an entire video. Multi-object tracking is then the extension to several cats per video \cite{luo2021mot}. This is absolutely necessary in order to be able to carry out a temporal analysis of a specific cat.
9In dieser Arbeit erzeugt ein Objektdetektor (in diesem Fall YOLO26) die Begrenzungsrahmen, diese enthalten die genauen Koordinaten der Objekte, in unserem Fall vom Gesicht der Katze. Im zweiten Schritt übernimmt der Tracker. Er versucht die neuen Erkennungen den bekannten zuzuordnen, sollte das nicht möglich sein wird eine neue Identität erzeugt \cite{bewley2016sort, kuhn1955hungarian}. Im Fall von ByteTrack \cite{zhang2022bytetrack} passiert dieses zuordnen durch Bewegungsvorhersagen welche der Kalman-Filter \cite{kalman1960new} trifft.In this thesis, an object detector (in this case YOLO26) produces the bounding boxes, which contain the exact coordinates of the objects, in our case of the cat's face. In the second step, the tracker takes over. It tries to assign the new detections to the known ones; if this is not possible, a new identity is created \cite{bewley2016sort, kuhn1955hungarian}. In the case of ByteTrack \cite{zhang2022bytetrack}, this assignment is done using motion predictions made by the Kalman filter \cite{kalman1960new}.
10ByteTrack hebt sich von klassischen Trackern \cite{bewley2016sort, wojke2017deepsort} ab indem er auch Erkennungen mit niedrigem Konfidenzwert verwendet um Identitätswechsel vorzubeugen, damit dies nicht zu Fehlalarmen führt, ordnet er im ersten Schritt die Begrenzungsrahmen mit hohen Konfidenzwerten zu \cite{zhang2022bytetrack}. Anschließend werden die Objekte mit den niedrigen Konfidenzwerten verglichen welche im vorigen Schritt nicht zugeordnet werden konnten. Dadurch wird die Verfolgung robuster bei Verdeckungen \cite{zhang2022bytetrack}. Daher eignet sich ByteTrack ideal für unvorhersehbare Bewegungen und Okklusionen beim Anwendungsfall einer Katzenklappe.ByteTrack differs from classic trackers \cite{bewley2016sort, wojke2017deepsort} in that it also uses detections with a low confidence score in order to prevent identity switches. So that this does not lead to false alarms, it first assigns the bounding boxes with high confidence scores \cite{zhang2022bytetrack}. Subsequently, the objects with low confidence scores that could not be assigned in the previous step are compared. This makes the tracking more robust against occlusions \cite{zhang2022bytetrack}. ByteTrack is therefore ideally suited to unpredictable movements and occlusions in the use case of a cat flap.

Diese Netzwerke sind durch ihre Archtitektur für schnelle Inferenz bei hoher Genauigkeit ausgelegt \cite{bolya2019yolact}.Like object detection, segmentation works on the principle of convolutional neural networks \cite{lecun1998gradient, long2015fcn}. Modern YOLO versions, such as YOLO26 in our case, offer not only object detection but also segmentation \cite{jocher2024yolo}. Owing to their architecture, these networks are designed for fast inference at high accuracy \cite{bolya2019yolact}.
13Während die Objekterkennung uns zeigt wo sich eine Katze befindet, wissen wir aber noch nicht ob eine Katze Beute im Mund trägt oder nicht. Hier kommt die Bildsegmentierung zum Einsatz \cite{minaee2022segmentation, he2017maskrcnn}. Dieser Ansatz hat den Vorteil dass die Segmentierung nicht mehr das ganze Bild verstehen muss, das Modell bekommt lediglich einen Ausschnitt um das Gesicht der Katze, dieser Ansatz benötigt einen wesentlich kleineren Datensatz, da die Segmentierung immer eine ähnliche Aufgabe mit wenig Varianz bekommt.While object detection shows us where a cat is located, we still do not know whether or not a cat is carrying prey in its mouth. This is where image segmentation comes into play \cite{minaee2022segmentation, he2017maskrcnn}. This approach has the advantage that the segmentation no longer has to understand the whole image; the model only receives a crop around the cat's face. This approach requires a considerably smaller dataset, since the segmentation always receives a similar task with little variance.
14Die Aufgabe des Segmentierungsmodells ist somit, die Beute im Maul der Katze pixelgenau zu markieren. Für jedes gefundene Beutetier liefert das Modell eine Maske und einen Konfidenzwert. Der höchste Konfidenzwert eines Bildausschnitts gibt an, wie wahrscheinlich die Katze Beute trägt. Findet das Modell keine Beute, ist der Wert 0.The task of the segmentation model is thus to mark the prey in the cat's mouth with pixel accuracy. For each prey animal found, the model delivers a mask and a confidence score. The highest confidence score of a crop indicates how likely it is that the cat is carrying prey. If the model finds no prey, the value is 0.
15\section{Zustandsautomaten} \label{subsec:fsm}\section{State Machines} \label{subsec:fsm}
16Während der Objektdetektor und die Segmentierung Momentaufnahmen liefern, welche durchaus schwanken können, hilft uns bei der Entscheidung ein Zustandsautomat. Er aggregiert die Ergebnisse von Detektor und Segmentierung zeitlich, dadurch wird das Ergebnis nicht stark durch Ausreißer beeinflusst, und wird robuster gegen Fehler \cite{han2016seqnms, kang2018tcnn}.While the object detector and the segmentation deliver snapshots, which can certainly fluctuate, a state machine helps us with the decision. It aggregates the results of the detector and the segmentation over time, so that the result is not strongly influenced by outliers and becomes more robust against errors \cite{han2016seqnms, kang2018tcnn}.
17Ein endlicher Zustandsautomat ist ein Modell, welches eine endliche Menge an Zuständen beinhaltet \cite{hopcroft2006automata}. Das Modell befindet sich zu einem Zeitpunkt immer in genau einem Zustand. Durch bestimmte Ereignisse oder erfüllen bestimmter Bedingungen, wird der aktuelle Zustand des Automaten bestimmt, z.B. wenn der durchschnittliche Konfidenzwert der letzten 20 Einzelbilder über 0,3 liegt, dann wechselt der Zustandsautomat auf Zugang verweigert \cite{harel1987statecharts}. Der Übergang von einem Zustand löst für gewöhnlich auch Aktionen aus, in unserem Fall würden wir die Katzenklappe öffnen oder schließen \cite{mealy1955method, moore1956gedanken}.A finite state machine is a model that contains a finite set of states \cite{hopcroft2006automata}. At any point in time, the model is in exactly one state. The current state of the automaton is determined by certain events or the fulfilment of certain conditions, e.g.\ if the average confidence score of the last 20 frames is above 0.3, the state machine switches to access denied \cite{harel1987statecharts}. A transition from one state usually also triggers actions; in our case, we would open or close the cat flap \cite{mealy1955method, moore1956gedanken}.
18Ein einfaches Beispiel für einen Zustandsautomaten ist eine Ampel, das Modell repräsentiert ob die Ampel Rot, Gelb oder Grün ist. Bedingung für das Wechseln ist ein Timer. Die Aktion wäre das Umschalten der Ampel.A simple example of a state machine is a traffic light; the model represents whether the traffic light is red, yellow or green. The condition for switching is a timer. The action would be the switching of the traffic light.
19In unserem Kontext dient der Zustandsautomat Ungenauigkeiten der Objekterkennung und Segmentierung zu glätten. Anstatt bei einem Ausreißer sofort den Zustand der Katzenklappe zu ändern, wird der Zustandsübergang an Bedingungen (z.b. einen Schwellenwert über ein Zeitfenster) gebunden.In our context, the state machine serves to smooth out inaccuracies of the object detection and segmentation. Instead of immediately changing the state of the cat flap in the case of an outlier, the state transition is tied to conditions (e.g.\ a threshold over a time window).
